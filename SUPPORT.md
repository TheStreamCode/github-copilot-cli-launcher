# Support

## Reporting Issues

Open a GitHub issue for bugs and feature requests:

- [GitHub Issues](https://github.com/TheStreamCode/github-copilot-cli-launcher/issues)

When reporting a bug, please include:

- VS Code version
- Operating system and version
- Extension version
- Steps to reproduce the issue

## Questions and Workflows

Use [GitHub Discussions](https://github.com/TheStreamCode/github-copilot-cli-launcher/discussions) for usage questions and workflows. Reproducible defects belong in the issue forms.

## Contact
